# Ravenor's Stories

Ravenor's Stories (formerly Ravenor's Adventure) is a turn-based dungeon crawler in which you control a party of adventurers investigating mysterious disappearances.

# Developed Systems

## Combat
- Character class and stats system
- Spell system
- Enemy AI system

## Navigation
- Grid-based movement system
- Pathfinding

## Narrative
- Dialogue system

# Architecture and Design
- Design of modular and generic systems, allowing high flexibility of use (especially for the spell system)
- Architecture based on separation of concerns to facilitate the addition, maintenance, and removal of different systems
- Management and maintenance of a long-term project independently

# Skills Developed
- Design of complex systems in C#
- Software architecture focused on modularity and extensibility
- Independent long-term project management
